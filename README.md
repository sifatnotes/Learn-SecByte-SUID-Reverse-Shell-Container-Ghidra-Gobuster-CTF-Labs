# Learn SecByte SUID, Reverse Shell, Container, Ghidra & Gobuster CTF Labs

A focused collection of hands-on cybersecurity and CTF labs from Learn SecByte covering SUID binary discovery, hash cracking, reverse engineering with Ghidra, UPX unpacking, container security, hidden files, reverse shells, command injection, and Gobuster enumeration.

These labs are useful for cybersecurity students, CTF players, penetration testers, SOC analysts, and security learners developing practical Linux, binary-analysis, and web-security skills.

## Introduction

Practical cybersecurity training involves multiple stages, from discovering files and services to analyzing binaries, understanding privilege boundaries, and investigating application vulnerabilities.

This repository organizes Learn SecByte labs around Linux privilege escalation, binary analysis, cryptographic hash recovery, container security, shell access, command injection, and web enumeration.

## Learning Path

A practical sequence for this collection is:

1. Begin with **Hidden File Pursuit** and **Gobuster Gap** for file and web enumeration.
2. Study **SUID Sleuth Binary Hunt** to understand SUID-based privilege boundaries.
3. Continue with **Hash Crack Relay** for hash and credential-security concepts.
4. Explore **Ghidra Breakout** and **UPX Unpacked the Hidden Shell** for binary analysis and reverse engineering.
5. Work through **Container Crackdown**, **Containment Ladder**, and **Containment Leak** to study container security.
6. Practice **Shellgate Reverse Shell Primer** to understand controlled shell-access scenarios.
7. Study **Command Injection Conveyor** and **Container Chain Injection** for application and container injection concepts.

## How to Use the Labs

- Use all exercises only in authorized and isolated lab environments.
- Start with reconnaissance and identify the intended attack surface.
- Document discovered files, binaries, services, and application behavior.
- Analyze SUID permissions before attempting privilege escalation.
- Use Ghidra and UPX-related techniques only against binaries provided for the lab.
- Treat recovered hashes and credentials as lab-only data.
- Practice reverse shells only against systems you are authorized to control.
- Analyze command-injection vulnerabilities and their defensive mitigations.
- Document each finding and explain how the vulnerability could be prevented.
